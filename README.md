# Sa'adah Dashboard

## Setup Environment 
```
conda create --name project-bangkit python=3.10
conda activate project-bangkit
```

## Setup Environment - Shell/Terminal
```
mkdir project_with_bangkit
cd dashboard
```

## Run steamlit app
```
streamlit run dashboard.py
```
